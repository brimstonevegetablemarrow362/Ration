## 🛠️ Troubleshooting Common Issues

### Ration Doesn't Show in System Tray
1. Click the **up arrow** (^) near your clock to see hidden icons
2. Drag Ration to your visible tray area if you want it always visible
3. If you don't see it at all, check that Ration is running in your Task Manager

### Ration Isn't Tracking My Activity
1. Make sure Ration is running (check the tray)
2. Verify you're using a supported AI tool (Claude Code or Codex)
3. Restart Ration by right-clicking its icon and selecting "Restart"

### Notifications Aren't Working
1. Check your Windows notification settings - make sure notifications are allowed for Ration
2. Verify your threshold is set correctly in Settings
3. Ensure your system volume isn't muted
